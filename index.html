How to process a refund

  1. 1Verify fare rules (CAT 16) in the GDS before quoting.
  2. 2Cancel all segments if unused, or identify unused segments for partial refund.
  3. 3Submit refund via airline refund desk / ARC report.
  4. 4Log the case as Full refund (7 pts) or Partial refund (16 pts).
  5. 5Send Refund Request Acknowledged template to passenger.

How to handle name corrections

  1. 1Check the airline policy in Name Correction Policies page.
  2. 2Collect passport copy from passenger.
  3. 3Apply the GDS name-change command for the airline.
  4. 4Contact trade desk if the ticket was already issued.
  5. 5Log as Name correction (16 pts) and send confirmation template.

How to escalate to airline trade desk

  1. 1Exhaust the general line first — note the agent name and time.
  2. 2Open Airline Directory, find the Agency/Trade number.
  3. 3Have PNR, ticket number and passenger name ready.
  4. 4Use the Airline Trade Desk Escalation internal template.
  5. 5Log the escalation in the call notes.

How to handle irate passengers

  1. 1Listen fully without interrupting — let them vent.
  2. 2Acknowledge the frustration with a genuine apology.
  3. 3Offer 2 concrete options, not open-ended questions.
  4. 4Never promise airline outcomes you cannot control.
  5. 5Escalate to supervisor only after offering all options.

How to process exchanges

  1. 1Determine fully-unused (15 pts) vs partially-used (16 pts).
  2. 2Price the new itinerary in the GDS.
  3. 3Run the Fare Difference Calculator — recollect non-ref taxes.
  4. 4Collect fare difference + change fee before reissue.
  5. 5Reissue and verify the new e-ticket number.

How to handle schedule changes

  1. 1Confirm the change is airline-initiated (involuntary).
  2. 2Involuntary = free rebooking or full refund — no fees.
  3. 3Send Schedule Change Options template.
  4. 4If passenger accepts, rebook and confirm segments.
  5. 5Log as Inquiry (1 pt) or Exchange points if reissued.
